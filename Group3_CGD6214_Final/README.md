## ▶️ How to Run the Program

1. Open the solution file:  
   **`C:\project\Group3_CGD6214_Final\Group3_CGD6214_Final.sln`**

2. Configure the **project properties** and **libraries** if needed.

3. Run the project by pressing **F5** in Visual Studio.

⚠️ **Important Notes:**
- After launching, a **black screen** will appear — do not close it.  
- Wait until the terminal logs indicate that all **objects, shaders, and texture files** are loaded.  
- The program may take longer to load because it processes multiple heavy assets.  
- Once loaded, you can interact with the program using the available keyboard shortcuts.

---

## ⌨️ Keyboard Shortcuts

### GUI & Rendering
- **F1** – Toggle GUI  
- **F6** – Toggle Deferred Rendering  
- **M** – Cycle MSAA samples  
- **B** – Toggle Bloom  
- **N** – Adjust Bloom Intensity  
- **J/K** – Adjust HDR Exposure  
- **L** – Toggle Lighting Mode  
- **1/2/3** – Switch Wireframe Display Modes  
- **R** – Reset Camera Position  

### Performance Graph Colors
- **T** – Adjust Red value  
- **Y** – Adjust Green value  
- **U** – Adjust Blue value  

### Movement Controls
- **W/A/S/D** – Move camera  
- **SPACE** – Jump (only in first-person mode)  

⚠️ **Note:** Bloom and HDR can only be used when Deferred Rendering (**F6 mode**) is enabled.
